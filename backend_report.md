### **项目技术栈及技术特长**

---

#### **1. 服务器架构**

| **模块**                | **技术栈**                    | **技术特长**                                                             |
| ----------------------- | ----------------------------- | ------------------------------------------------------------------------ |
| **Gate Server**         | C++ + Asio + Beast            | 全异步链处理，高性能低延迟，适合高并发实时通信。                         |
| **Chat Server**         | C++ + Asio + Beast + 负载均衡 | 多实例部署，支持负载均衡和分布式架构，可水平扩展以应对高流量场景。       |
| **Status Server**       | C++ + Asio + Beast + gRPC     | 通过 gRPC 提供高效、强类型的接口，支持双向流通信，适合微服务间状态查询。 |
| **Verification Server** | Node.js + nodemail            | 轻量库快速处理邮箱验证，通过 gRPC 与 Gate Server 通信。                  |

---

#### **2. 通信协议**

| **协议/技术**              | **应用场景**                                                      | **技术特长**                                                             |
| -------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **gRPC**                   | 微服务间通信（Gate Server 与 Status Server、Verification Server） | 高效二进制序列化（Protobuf），低延迟，支持跨语言通信，适合复杂数据交互。 |
| **HTTPS RESTful API**      | 前端与 Gate Server 通信                                           | 安全加密传输，标准化接口设计，便于前后端分离开发。                       |
| **WSS (WebSocket Secure)** | 实时聊天功能（Chat Server 与 Web 端）                             | 双向实时通信，TLS 加密，解决 HTTP 轮询的高延迟问题，适合聊天场景。       |

---

#### **3. 用户认证与会话管理**

| **技术**          | **应用场景**                               | **技术特长**                                                                      |
| ----------------- | ------------------------------------------ | --------------------------------------------------------------------------------- |
| **客户端 Cookie** | 存储 User ID 或 Token，通过 HTTPS 安全传输 | 轻量级存储，支持跨域访问。                                                        |
| **Redis**         | 服务端存储 Token 和用户状态                | 高速键值存储，支持分布式部署，实现无状态会话管理（如 JWT 验证），适合高并发场景。 |

---

#### **4. 数据库与缓存**

| **组件**  | **技术栈**       | **技术特长**                                                                     |
| --------- | ---------------- | -------------------------------------------------------------------------------- |
| **Redis** | Key-Value 数据库 | 快速读写能力，支持缓存、实时数据处理（如消息队列、Token 验证），分布式部署支持。 |
| **MySQL** | 关系型数据库     | 持久化存储用户基本信息、对话历史等结构化数据，事务支持保障数据一致性。           |

---

#### **5. 其他关键技术**

| **技术**     | **应用场景**                        | **技术特长**                                                              |
| ------------ | ----------------------------------- | ------------------------------------------------------------------------- |
| **CORS**     | Chat Server 与 Gate Server 跨域通信 | 解决跨域资源共享问题，允许前端访问不同域的 Chat Server 服务。             |
| **负载均衡** | Chat Server 实例流量分发            | 通过 Nginx 或 Kubernetes Ingress 动态分配请求，提升系统吞吐量和容错能力。 |

---

### **总结**

- **核心优势**：基于 **C++ 异步框架**（Asio/Beast）实现高性能实时通信，结合 **gRPC 微服务通信** 和 **Redis 缓存**，支持高并发场景。
- **安全设计**：通过 **HTTPS/WSS 加密**、**Redis Token 验证** 和 **CORS 策略**，保障系统安全性。
- **扩展性**：**Chat Server 的负载均衡** 和 **分布式架构** 设计，支持横向扩展，适应流量增长需求。
